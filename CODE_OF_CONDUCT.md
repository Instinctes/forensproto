# Code of Conduct

## Our standard

Be respectful. Assume good faith. No harassment, hate, or personal attacks.

This project deals with recovery of sensitive material. Do not ask maintainers or other contributors to:

- recover, crack, or extract keys for wallets you do not own
- share private keys, seeds, or potfiles in issues or PRs
- help bypass someone else’s encryption or access control

## Enforcement

Maintainers may edit or close issues, refuse PRs, and block accounts that ignore this. Report CoC problems via GitHub, the same way you would a security issue if you need privacy: see [SECURITY.md](SECURITY.md).
